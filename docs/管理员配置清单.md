# 管理员配置清单（v1.6.3 企业微信群与邮件提醒）

v1.6.3 合并同类运行异常：一轮邮箱扫描结束后，将到期的同类故障合并为一条群消息，列出受影响邮箱并统一 @ 当前负责人；邮件兜底按负责人合并。同一邮箱同一类异常仍保留原来的每日去重规则，发送失败会重试，后台保留逐邮箱记录。普通业务来信仍即时提醒，不等待扫描汇总。

v1.6.2 群消息采用中文标题、北京时间和逐条处理建议；隐藏内部编号、原始JSON和冗长分类依据。日报保留全部业务及待人工复核邮件，系统操作按中文摘要列出，详细依据和完整操作记录仍可在助手中查看。长日报优先按段落、行和句子分条，标题显示日期及第几条／共几条。只调整群消息展示，原邮箱汇总和审计记录继续保留。

| 配置方 | 必需信息 |
|---|---|
| 阿里邮箱管理员 | 已有API应用Client ID、Client Secret；六邮箱的列表、读取、附件权限；需要移动时开通相应权限 |
| 提醒发件邮箱 | 完整地址；SMTP服务器；SSL/TLS或STARTTLS端口；客户端授权码；已开启程序发信权限。用于即时及复核提醒邮件兜底，以及每日完整汇总邮件投递，启用群提醒后仍需配置 |
| 企业微信内部群管理员 | 经授权的公司内部群及该群官方群机器人的 Webhook；群内全体成员均可见提醒内容 |
| 负责人 | 姓名及实际接收提醒的邮箱地址，必填；企业微信成员账号（userid）可选，用于群内 @，可随时更改 |
| AI管理员 | 服务地址、模型名称、API Key；未配置时保守转人工 |
| Windows管理员 | 全天联网、不睡眠的运行主机；数据目录和备份位置；正式安装系统服务时需管理员权限 |

1. 阿里邮箱和 AI 凭据统一加密保存在后端；在右上角“设置 → 更改系统连接”维护，修改后自动保存。已有密钥留空保留，更换负责人不需重填。
2. “设置 → 更改提醒发件箱”维护 SMTP 地址、端口、加密方式及授权码，自动保存。成功时显示“已自动保存”；失败保留原配置。
3. “设置 → 企业微信群提醒 → 更改企业微信群提醒”维护“启用企业微信群提醒”复选框及“群机器人 Webhook”密码框，自动保存。已有 Webhook 不回显，留空保留；关闭启用开关后使用邮件提醒，已存 Webhook 保留。保存不会发送测试群消息。
4. “管理负责人”新增或编辑姓名、提醒邮箱及可选的“企业微信成员账号（用于群内@）”，自动保存。成员账号须由管理员核对，不是姓名或手机号；留空时该负责人接收邮件。“发送测试邮件”为可选的独立 SMTP 测试按钮，只验证邮件通道。
5. “邮箱与负责人”中为每个邮箱勾选一位或多位负责人；同一人可负责多个邮箱。移除唯一负责人前先增加另一位。原有六邮箱李涵的归属在升级时保留。同一提醒合并为一条群消息并 @ 已配置成员账号的当前负责人，缺少成员账号的人单独收邮件；每日完整汇总按负责人分别发群和原提醒邮箱，群内 @ 该报告负责人；未启用群提醒或未填成员账号时只发邮件。

群机器人 Webhook 方式无需 CorpID、AgentID、自建应用 Secret、客户端可信 IP、可信域名或消息回调。需要群内 @ 的负责人可配置企业微信成员账号；它与助手自动生成的内部负责人标识不同。系统只有单向群提醒，没有入站消息回调、领取或完成交互；个人微信未接入。邮件在企业微信中的新邮件提示仍取决于邮箱接入和终端通知设置。

启用群提醒后，业务来信、首次处理复核、截止前复核及运行提示优先发群；这些提醒群接口报错或网络失败时改用 SMTP，负责人未配置成员账号时直接用邮件。每日北京时间18:00按负责人归集完整汇总，包含未即时提醒邮件的人工复核内容；已配置成员账号的负责人同步收群与原邮箱报告，群内 @ 该报告负责人，长内容编号分条、不截断；未启用群提醒或未填成员账号时只发邮件。群与SMTP分别记录进度，群失败重试当前未成功分片，重启后继续，不重复补发已成功邮件；群分片间隔4秒，即时提醒优先。沿用现有群开关，无新增开关或按钮。只有获授权的公司内部群可用于此设置；@ 只选择提醒对象，不能限制其他群成员查看提醒和汇总内容，敏感信息仍按原规则遮蔽。

请使用邮箱服务商提供且证书有效的SMTP主机名。常用SSL/TLS端口465、STARTTLS端口587，具体以服务商设置为准；程序不允许明文登录。

首次启用邮箱服务商的客户端授权码，可能需要同步更新原有邮件客户端密码。仅在本机页面输入授权码和群 Webhook，不发送到聊天、台账或文档。既有敏感信息不送 AI、通知遮蔽和转人工规则继续适用。

自动发送仅限内部通知；阿里API适配器没有客户发信、草稿或删除接口。按实际能授予的最小范围配置六个邮箱的读取及移动权限。

现场验收：新邮件到群并正确 @ 当前负责人；多人一条群提醒；成员账号缺失及群接口／网络失败改发邮件；历史邮件不处理；敏感信息不进入AI或通知；首次18点与截止前一小时；群和邮件汇总完整、编号分片及负责人 @；独立渠道重试与重启续发；换负责人；提交失败重试；客户端通知延迟；移动恢复；重启后保留启用时间。v1.6.0 在2026-10-12已完成Windows产品真实新来信联调，用户确认对应群消息、正确 @ 李涵、手机和电脑提示三项均正常，本次未触发SMTP兜底。v1.6.1 每日完整群汇总的真实北京时间18:00定时投递尚待核验，不能以此前新来信验收替代。跨电脑管理网页另需安全入口，当前仅监听本机。

免登录入口仅允许本机访问，并拒绝外部网页跨站调用。新电脑只需在网页首次配置一次，现有机器上的系统配置自动复用；换负责人不等于换运行电脑。
