# Oneasy 邮件助手 v1.6.12

v1.6.12：已确认测试邮件静默留档，不发送即时或办理复核提醒，也不作为每日对外汇总的待办或@对象。记住指定运营表单中客户姓名Oneasy SMOKE、公司SMOKE-日期编号的组合，仅在已确认发收件地址及表单主题下识别；普通客户申请不受此规则影响。

v1.6.11：明确模拟邮件标为测试邮件，仅验证提醒，无需实际开通或回复；不建议录入CRM或按真实需求办理。客户提出的截止时间与内部跟进建议分别保留、展示，只有有原文依据且来源明确的客户期限安排截止提醒，未知来源提示人工核对。

v1.6.9：官网广告、网站推广和AI／大模型收录推荐等明确推销列为无效广告，本地过滤，不即时提醒、不进入人工复核。明确广告附带的名片和广告示例图片不再提前触发人工提醒；原邮件及过滤记录保留，合同订单、客户请求、风险和敏感信息仍按原规则处理。

v1.6.8：明确的第三方营销推广标为“营销推广·已忽略”，不即时提醒、不进入待复核，也不按业务计数或@负责人。完整汇总和操作台账继续保留记录，可更正为业务邮件。普通系统通知仍归每日复核；客户业务、安全风险和敏感信息保持原处理方式。

v1.6.7：待复核列表和首页数量仅统计尚未复核的非业务邮件。经明确确认的记录标记为已复核，仍保留在台账和完整汇总中，单独展示且不再要求重复复核。已发送或已开始分条发送的旧日报保留原格式和进度。分类复核不代表客户业务已完成。

v1.6.6：修正推广邮件因退订链接token参数被误判为访问凭证的问题。仅移除明确退订链接，再进行敏感检查及AI分类；登录、改密、真实凭证和设备信息仍保守转人工。AI区分第三方销售推广与客户服务请求，非业务判断保留高置信度及可核对原文依据。对已核实的阿里邮箱完整定期改密模板，在无额外风险或凭证时本地归入每日复核，提供明确摘要；不因发件人含no-reply就统一忽略。

v1.6.5：每日群汇总和邮件汇总仅展示本期邮件，不再附带系统操作摘要或操作日志。没有业务来信和待人工复核邮件时，只展示日期、统计时段和0封数量，不显示末尾业务处理／人工复核提示。有邮件时仍保留完整清单和处理提示。后台操作台账及汇总详情中的操作记录继续保留，定时时间、负责人和@规则沿用原有配置。已经开始分条发送的旧日报按原进度发完，之后的新日报使用精简格式。

这是 Oneasy 邮件助手的源码仓库，保存前后端、部署脚本、测试及使用说明。版本变化见 [更新记录](CHANGELOG.md)，后续修改可通过 GitHub 提交记录查看。

## 代码构成

| 位置 | 内容 |
| --- | --- |
| `app/` | 邮箱接入、AI 分类、监控、任务调度、通知、数据台账和本机管理接口 |

## 源码预览与检查

建议使用 Python 3.13，在独立虚拟环境中安装 `requirements.txt` 后，从仓库根目录运行：

```sh
python -m app demo --data demo-data --port 18766
```

浏览器打开 `http://127.0.0.1:18766/`。演示使用构造数据，不连接真实邮箱或发送提醒；请勿将演示数据目录指向正式安装目录。

```sh
python -m unittest discover -s tests -t . -q
node --test tests/test_runtime_ui.js tests/test_wecom_settings_ui.js
```

正式使用请按照 [部署说明](docs/Windows与Mac部署说明.txt) 使用完整交付包。这个源码仓库不包含离线 Python、系统安装资源、第三方依赖二进制和生成的 `manifest.json`，不能把 GitHub 的“Download ZIP”直接当作一键安装包。已有完整交付包保存在交付目录中。

Oneasy 邮件助手 v1.6.1 — 客户端运行控制

右上角三个图标：
■ 暂停监控：暂停检测、AI分析、自动移动、提醒发送和汇总调度；管理页面保留。
○ 恢复监控：暂停后显示，恢复处理并补查仍在监控范围内的新邮件；不改变原启用时间。
↓ 隐藏到后台：只关专用客户端窗口，后台保持原运行/暂停状态。
× 完全退出：二次确认后正规停止后台并关专用窗口，配置和历史保留。
窗口自带的×仍只关界面，后台继续。

暂停状态持久保存，重启后仍需主动恢复。已经开始的读取/发送可能完成，已发送邮件不能撤回。
控制操作先尝试保存当前表单；保存失败不执行。
隐藏/退出通过本机原生助手执行，浏览器首次可能询问是否打开Oneasy邮件助手；请允许。
Windows及Mac正规停止/重新启动后台可能需要管理员授权，取消则保持未完成状态。
默认浏览器回退不能保证自动关窗口，按提示手动关闭即可；不影响正规停止后台的结果。
Mac控制仍需真实Mac验收；Windows实际验证范围见验证记录。

升级：在原监控电脑重新运行交付包对应部署脚本，保留现有配置、负责人、启用时间及记录。
新电脑仍需首次配置一次，包内不包含公司密钥或历史数据。同一组邮箱只启用一台电脑。
