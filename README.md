# Oneasy 邮件助手 v1.6.3

这是 Oneasy 邮件助手的源码仓库，保存前后端、部署脚本、测试及使用说明。版本变化见 [更新记录](CHANGELOG.md)，后续修改可通过 GitHub 提交记录查看。

## 代码构成

| 位置 | 内容 |
| --- | --- |
| `app/` | 邮箱接入、AI 分类、监控、任务调度、通知、数据台账和本机管理接口 |
| `app/static/` | 管理页面的 HTML、CSS、JavaScript 和图标 |
| `scripts/` | Windows / Mac 部署、启动和客户端控制脚本 |
| `packaging/` | Windows / Mac 统一部署入口的页面源码 |
| `tests/` | 后端与前端行为检查 |
| `docs/` | 使用手册、管理员配置清单、部署说明和验收记录 |
| `requirements.txt` | 源码运行的 Python 依赖版本 |

## 源码预览与检查

建议使用 Python 3.13，在独立虚拟环境中安装 `requirements.txt` 后，从仓库根目录运行：

```sh
python -m app demo --data demo-data --port 18766
```

浏览器打开 `http://127.0.0.1:18766/`。演示使用构造数据，不连接真实邮箱或发送提醒；请勿将演示数据目录指向正式安装目录。

```sh
python -m unittest discover -s tests -t . -q
node --test tests/test_runtime_ui.js tests/test_wecom_settings_ui.js
```

正式使用请按照 [部署说明](docs/Windows与Mac部署说明.txt) 使用完整交付包。这个源码仓库不包含离线 Python、系统安装资源、第三方依赖二进制和生成的 `manifest.json`，不能把 GitHub 的“Download ZIP”直接当作一键安装包。已有完整交付包保存在交付目录中。

## 配置和更新

阿里邮箱密钥、AI 密钥、SMTP 授权码、企业微信群 Webhook、客户邮件记录及本机数据库均不进入 Git 仓库。它们继续保存在部署电脑，由现有管理页面维护。测试中的假密钥和示例地址仅用于离线检查。

更新代码时同步维护 `CHANGELOG.md` 并运行相关检查；提交到 GitHub 只更新源码，不会自动升级运行中的助手。安装升级仍使用经过校验的完整交付包。

完整页面和按钮说明见 [详细使用说明](docs/详细使用说明.html)（下载后用浏览器打开）。下文保留交付版本说明。

v1.6.3 合并同类运行异常：一轮邮箱扫描结束后，将到期的同类故障合并为一条群消息，列出受影响邮箱并统一 @ 当前负责人；邮件兜底按负责人合并。同一邮箱同一类异常仍保留原来的每日去重规则，发送失败会重试，后台保留逐邮箱记录。普通业务来信仍即时提醒，不等待扫描汇总。

v1.6.2 群消息采用中文标题、北京时间和逐条处理建议；隐藏内部编号、原始JSON和冗长分类依据。日报保留全部业务及待人工复核邮件，系统操作按中文摘要列出，详细依据和完整操作记录仍可在助手中查看。长日报优先按段落、行和句子分条，标题显示日期及第几条／共几条。只调整群消息展示，原邮箱汇总和审计记录继续保留。

Windows / Mac 统一部署包，自带运行环境。完整解压后返回上一级，双击 `部署邮件助手.html`，按系统指引运行安装资源中的原生安装程序。
请先阅读 `先读我_部署与使用说明.txt`，其中包含新电脑接入、日常使用、升级、故障处理和代码位置。

桌面端使用 Edge / Chrome 独立窗口，后台使用 Windows 服务或 Mac 系统服务，关闭窗口后保持原监控状态。
全新电脑首次需要管理员配置一次；同机更换负责人和重复部署保留配置。

v1.6 支持官方企业微信内部群机器人 Webhook。启用后，业务来信、首次处理复核、截止前复核及运行提示优先发送到同一内部群，一条提醒合并 @ 已配置企业微信成员账号的当前负责人；未填写成员账号的负责人，或群接口／网络发送失败时，使用原 SMTP 邮件提醒。

v1.6.1 将每日完整汇总同时发送到企业微信群和原提醒邮箱。每天北京时间 18:00 按负责人归集，包含未即时提醒邮件的人工复核内容；群内 @ 该报告负责人，长内容按编号分条发送，不截断。群与 SMTP 分别记录进度；群失败重试当前未成功分片，重启后继续，群分片间隔 4 秒，即时提醒优先。未启用群提醒或负责人未填成员账号时只发邮件，沿用现有群开关，无新增开关或按钮。

管理员从右上角“设置 → 企业微信群提醒 → 更改企业微信群提醒”维护启用开关及群机器人 Webhook，修改后自动保存；Webhook 为密码框，已有值留空保留。负责人编辑页可选填“企业微信成员账号（用于群内@）”，提醒邮箱仍必填。群内全体成员均可见内容，仅使用已获授权的公司内部群；敏感信息不送 AI、通知遮蔽及人工处理规则保持原有要求。没有自动回复或删除客户邮件、入站消息回调或群内交互；个人微信未接入。

Oneasy 邮件助手 v1.6.1 — 客户端运行控制

右上角三个图标：
■ 暂停监控：暂停检测、AI分析、自动移动、提醒发送和汇总调度；管理页面保留。
○ 恢复监控：暂停后显示，恢复处理并补查仍在监控范围内的新邮件；不改变原启用时间。
↓ 隐藏到后台：只关专用客户端窗口，后台保持原运行/暂停状态。
× 完全退出：二次确认后正规停止后台并关专用窗口，配置和历史保留。
窗口自带的×仍只关界面，后台继续。

暂停状态持久保存，重启后仍需主动恢复。已经开始的读取/发送可能完成，已发送邮件不能撤回。
控制操作先尝试保存当前表单；保存失败不执行。
隐藏/退出通过本机原生助手执行，浏览器首次可能询问是否打开Oneasy邮件助手；请允许。
Windows及Mac正规停止/重新启动后台可能需要管理员授权，取消则保持未完成状态。
默认浏览器回退不能保证自动关窗口，按提示手动关闭即可；不影响正规停止后台的结果。
Mac控制仍需真实Mac验收；Windows实际验证范围见验证记录。

升级：在原监控电脑重新运行交付包对应部署脚本，保留现有配置、负责人、启用时间及记录。
新电脑仍需首次配置一次，包内不包含公司密钥或历史数据。同一组邮箱只启用一台电脑。
